# Engagement Checklist

- Confirm exact in-scope domains, apps, APIs, mobile backends, and third-party exclusions.
- Record forbidden techniques (DoS, social engineering, physical testing, credential stuffing, mass scanning, etc.).
- Define a request-rate ceiling below the program limit.
- Use dedicated test accounts and non-sensitive test data.
- Keep a timestamped evidence log.
- Capture request/response pairs for every suspected issue.
- Reproduce manually before reporting.
- Avoid accessing data beyond the minimum needed to prove impact.
- Stop immediately if testing causes instability or unexpected user impact.
- Remove temporary test artifacts when finished.
